# New-FilesPublicKey

## SYNOPSIS

Create Public Key.

## SYNTAX

### __AllParameterSets

```
New-FilesPublicKey [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Public Key.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Create Public Key

```powershell
New-FilesPublicKey -Title 'My Main Key' -GenerateAlgorithm 'rsa' -GenerateLength 1
```

Writes the public key returned.

### Example 2: Preview the change

```powershell
New-FilesPublicKey -Title 'My Main Key' -GenerateAlgorithm 'rsa' -GenerateLength 1 -WhatIf
```

Describes the change without sending anything to Files.com.
