# New-FilesRemoteServer

## SYNOPSIS

Create Remote Server.

## SYNTAX

### __AllParameterSets

```
New-FilesRemoteServer [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Remote Server.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Create Remote Server

```powershell
New-FilesRemoteServer -AllowRelativePaths $true -AwsAccessKey 'example'
```

Writes the remote server returned.

### Example 2: Preview the change

```powershell
New-FilesRemoteServer -AllowRelativePaths $true -AwsAccessKey 'example' -WhatIf
```

Describes the change without sending anything to Files.com.
