# New-FilesFile

## SYNOPSIS

Upload File.

## SYNTAX

### __AllParameterSets

```
New-FilesFile [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Upload File.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Upload File

```powershell
New-FilesFile -Path 'path' -CustomMetadata @{ department = 'finance' }
```

Writes the remote file returned.

### Example 2: Preview the change

```powershell
New-FilesFile -Path 'path' -CustomMetadata @{ department = 'finance' } -WhatIf
```

Describes the change without sending anything to Files.com.
