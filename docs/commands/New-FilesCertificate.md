# New-FilesCertificate

## SYNOPSIS

Create CSR or import existing SSL Certificate.

## SYNTAX

### __AllParameterSets

```
New-FilesCertificate [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create CSR or import existing SSL Certificate.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create CSR or import existing SSL Certificate

```powershell
New-FilesCertificate -Name 'Name' -CertificateDomain 'domain.com' -CertificateExtraDomains 'www.domain.com'
```

Writes the certificate returned.

### Example 2: Preview the change

```powershell
New-FilesCertificate -Name 'Name' -CertificateDomain 'domain.com' -CertificateExtraDomains 'www.domain.com' -WhatIf
```

Describes the change without sending anything to Files.com.
