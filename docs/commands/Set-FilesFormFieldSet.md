# Set-FilesFormFieldSet

## SYNOPSIS

Update Form Field Set.

## SYNTAX

### Id (Default)

```
Set-FilesFormFieldSet [<parameters of the Id set>]
```

### InputObject

```
Set-FilesFormFieldSet [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Form Field Set.

The command accepts form field sets from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Update Form Field Set

```powershell
Set-FilesFormFieldSet -Id 1
```

Writes the form field set as Files.com returns it.

### Example 2: Act on form field sets from the pipeline

```powershell
Get-FilesFormFieldSet -Id 1 | Set-FilesFormFieldSet
```

Takes the form field set from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesFormFieldSet -Id 1 -WhatIf
```

Describes the change without sending anything to Files.com.
