# Get-FilesPartnerSiteRequestByPairingKey

## SYNOPSIS

Find partner site request by pairing key.

## SYNTAX

### __AllParameterSets

```
Get-FilesPartnerSiteRequestByPairingKey [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Find partner site request by pairing key.

## EXAMPLES

### Example 1: Find partner site request by pairing key

```powershell
Get-FilesPartnerSiteRequestByPairingKey -PairingKey 'pairing_key'
```

Sends the request and writes nothing when it succeeds.
