# Set-FilesShareGroup

## SYNOPSIS

Update Share Group.

## SYNTAX

### Id (Default)

```
Set-FilesShareGroup [<parameters of the Id set>]
```

### InputObject

```
Set-FilesShareGroup [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Share Group.

The command accepts share groups from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Update Share Group

```powershell
Set-FilesShareGroup -Id 1 -Notes 'This group is defined for testing purposes' -Name 'Test group 1'
```

Writes the share group as Files.com returns it.

### Example 2: Act on share groups from the pipeline

```powershell
Get-FilesShareGroup -Id 1 | Set-FilesShareGroup -Notes 'This group is defined for testing purposes' -Name 'Test group 1'
```

Takes the share group from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesShareGroup -Id 1 -Notes 'This group is defined for testing purposes' -Name 'Test group 1' -WhatIf
```

Describes the change without sending anything to Files.com.
