# Approve-FilesPartnerSiteRequest

## SYNOPSIS

Approve partner site request.

## SYNTAX

### __AllParameterSets

```
Approve-FilesPartnerSiteRequest [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Approve partner site request.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Approve partner site request

```powershell
Approve-FilesPartnerSiteRequest -PairingKey 'pairing_key'
```

Sends the request and writes nothing when it succeeds.

### Example 2: Preview the change

```powershell
Approve-FilesPartnerSiteRequest -PairingKey 'pairing_key' -WhatIf
```

Describes the change without sending anything to Files.com.
