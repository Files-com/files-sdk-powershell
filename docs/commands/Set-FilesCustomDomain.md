# Set-FilesCustomDomain

## SYNOPSIS

Update Custom Domain.

## SYNTAX

### Id (Default)

```
Set-FilesCustomDomain [<parameters of the Id set>]
```

### InputObject

```
Set-FilesCustomDomain [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Custom Domain.

The command accepts custom domains from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Update Custom Domain

```powershell
Set-FilesCustomDomain -Id 1 -WorkspaceId 1 -Destination 'site_alias'
```

Writes the custom domain as Files.com returns it.

### Example 2: Act on custom domains from the pipeline

```powershell
Get-FilesCustomDomain -Id 1 | Set-FilesCustomDomain -WorkspaceId 1 -Destination 'site_alias'
```

Takes the custom domain from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesCustomDomain -Id 1 -WorkspaceId 1 -Destination 'site_alias' -WhatIf
```

Describes the change without sending anything to Files.com.
