# Convert-FilesFile

## SYNOPSIS

Transform a file and save the output to a destination path.

## SYNTAX

### Path (Default)

```
Convert-FilesFile [<parameters of the Path set>]
```

### InputObject

```
Convert-FilesFile [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Transform a file and save the output to a destination path.

The command accepts files from the pipeline as -InputObject, and uses each one's Path and the connection that fetched it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Transform a file and save the output to a destination path

```powershell
Convert-FilesFile -Path 'path' -Destination 'destination' -TransformType 'transform_type' -TargetFormat 'target_format'
```

Writes the file action returned.

### Example 2: Act on files from the pipeline

```powershell
Get-FilesFile -Path 'path' | Convert-FilesFile -Destination 'destination' -TransformType 'transform_type' -TargetFormat 'target_format'
```

Takes the file from the pipeline and uses its Path and connection.

### Example 3: Preview the change

```powershell
Convert-FilesFile -Path 'path' -Destination 'destination' -TransformType 'transform_type' -TargetFormat 'target_format' -WhatIf
```

Describes the change without sending anything to Files.com.
