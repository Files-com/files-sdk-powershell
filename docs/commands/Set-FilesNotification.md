# Set-FilesNotification

## SYNOPSIS

Update Notification.

## SYNTAX

### Id (Default)

```
Set-FilesNotification [<parameters of the Id set>]
```

### InputObject

```
Set-FilesNotification [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Notification.

The command accepts notifications from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Update Notification

```powershell
Set-FilesNotification -Id 1 -NotifyOnDelete $true -NotifyOnDownload $true
```

Writes the notification as Files.com returns it.

### Example 2: Act on notifications from the pipeline

```powershell
Get-FilesNotification -Id 1 | Set-FilesNotification -NotifyOnDelete $true -NotifyOnDownload $true
```

Takes the notification from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesNotification -Id 1 -NotifyOnDelete $true -NotifyOnDownload $true -WhatIf
```

Describes the change without sending anything to Files.com.
