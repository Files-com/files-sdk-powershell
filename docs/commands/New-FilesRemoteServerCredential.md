# New-FilesRemoteServerCredential

## SYNOPSIS

Create Remote Server Credential.

## SYNTAX

### __AllParameterSets

```
New-FilesRemoteServerCredential [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Remote Server Credential.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Create Remote Server Credential

```powershell
New-FilesRemoteServerCredential -Name 'My Credential' -Description 'More information or notes about this credential.'
```

Writes the remote server credential returned.

### Example 2: Preview the change

```powershell
New-FilesRemoteServerCredential -Name 'My Credential' -Description 'More information or notes about this credential.' -WhatIf
```

Describes the change without sending anything to Files.com.
