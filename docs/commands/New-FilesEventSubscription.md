# New-FilesEventSubscription

## SYNOPSIS

Create Event Subscription.

## SYNTAX

### __AllParameterSets

```
New-FilesEventSubscription [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Event Subscription.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create Event Subscription

```powershell
New-FilesEventSubscription -Name 'example' -EventChannelId 1 -WorkspaceId 1
```

Writes the event subscription returned.

### Example 2: Preview the change

```powershell
New-FilesEventSubscription -Name 'example' -EventChannelId 1 -WorkspaceId 1 -WhatIf
```

Describes the change without sending anything to Files.com.
