# New-FilesLock

## SYNOPSIS

Create Lock.

## SYNTAX

### __AllParameterSets

```
New-FilesLock [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Lock.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create Lock

```powershell
New-FilesLock -Path 'locked_file' -Recursive $true -Owner 'user'
```

Writes the lock returned.

### Example 2: Preview the change

```powershell
New-FilesLock -Path 'locked_file' -Recursive $true -Owner 'user' -WhatIf
```

Describes the change without sending anything to Files.com.
