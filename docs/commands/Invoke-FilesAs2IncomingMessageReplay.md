# Invoke-FilesAs2IncomingMessageReplay

## SYNOPSIS

Replay AS2 Incoming Message.

## SYNTAX

### Id (Default)

```
Invoke-FilesAs2IncomingMessageReplay [<parameters of the Id set>]
```

### InputObject

```
Invoke-FilesAs2IncomingMessageReplay [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Replay AS2 Incoming Message.

The command accepts as2 incoming messages from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Replay AS2 Incoming Message

```powershell
Invoke-FilesAs2IncomingMessageReplay -Id 1
```

Writes the as2 incoming message as Files.com returns it.

### Example 2: Act on as2 incoming messages from the pipeline

```powershell
Get-FilesAs2IncomingMessage -Id 1 | Invoke-FilesAs2IncomingMessageReplay
```

Takes the as2 incoming message from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Invoke-FilesAs2IncomingMessageReplay -Id 1 -WhatIf
```

Describes the change without sending anything to Files.com.
