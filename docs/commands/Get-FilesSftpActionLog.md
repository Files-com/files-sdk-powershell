# Get-FilesSftpActionLog

## SYNOPSIS

List SFTP Action Logs.

## SYNTAX

### List (Default)

```
Get-FilesSftpActionLog [<parameters of the List set>]
```

### Page

```
Get-FilesSftpActionLog [<parameters of the Page set>]
```

### Continuation

```
Get-FilesSftpActionLog [<parameters of the Continuation set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

List SFTP Action Logs.

Without -Page or -Continuation, the command writes each sftp action log of every page, loading one page at a time as the pipeline consumes them. -First and -Skip bound what it writes, and stopping the pipeline early, as Select-Object -First does, loads no further page. A failure on any page stops the command, so a partial listing is never taken for a complete one.

## EXAMPLES

### Example 1: List all sftp action logs

```powershell
Get-FilesSftpActionLog
```

Writes every sftp action log, loading one page at a time as the pipeline consumes them.

### Example 2: Get one page at a time

```powershell
$page = Get-FilesSftpActionLog -Page
$next = Get-FilesSftpActionLog -Continuation $page.Continuation
```

Writes the first page as a FilesPage object, then the next page from its continuation.
