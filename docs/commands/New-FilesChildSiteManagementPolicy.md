# New-FilesChildSiteManagementPolicy

## SYNOPSIS

Create Child Site Management Policy.

## SYNTAX

### __AllParameterSets

```
New-FilesChildSiteManagementPolicy [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Child Site Management Policy.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Create Child Site Management Policy

```powershell
New-FilesChildSiteManagementPolicy -PolicyType 'settings' -Value @{ color2_left = '#000000'; folder_behaviors = @(@{ behavior = 'file_expiration'; value = @{ days_to_retain = 30 } }) } -SkipChildSiteIds 1, 2
```

Writes the child site management policy returned.

### Example 2: Preview the change

```powershell
New-FilesChildSiteManagementPolicy -PolicyType 'settings' -Value @{ color2_left = '#000000'; folder_behaviors = @(@{ behavior = 'file_expiration'; value = @{ days_to_retain = 30 } }) } -SkipChildSiteIds 1, 2 -WhatIf
```

Describes the change without sending anything to Files.com.
