# New-FilesEventTarget

## SYNOPSIS

Create Event Target.

## SYNTAX

### __AllParameterSets

```
New-FilesEventTarget [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Event Target.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create Event Target

```powershell
New-FilesEventTarget -Name 'example' -Config @{ url = 'https://example.com/files-events'; headers = @{ 'X-Example' = 'value' }; use_dedicated_ips = $false } -TargetType 'webhook' -WorkspaceId 1 -ApplyToAllWorkspaces $true
```

Writes the event target returned.

### Example 2: Preview the change

```powershell
New-FilesEventTarget -Name 'example' -Config @{ url = 'https://example.com/files-events'; headers = @{ 'X-Example' = 'value' }; use_dedicated_ips = $false } -TargetType 'webhook' -WorkspaceId 1 -ApplyToAllWorkspaces $true -WhatIf
```

Describes the change without sending anything to Files.com.
