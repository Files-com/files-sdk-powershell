# Set-FilesKeyLifecycleRule

## SYNOPSIS

Update Key Lifecycle Rule.

## SYNTAX

### Id (Default)

```
Set-FilesKeyLifecycleRule [<parameters of the Id set>]
```

### InputObject

```
Set-FilesKeyLifecycleRule [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Key Lifecycle Rule.

The command accepts key lifecycle rules from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Update Key Lifecycle Rule

```powershell
Set-FilesKeyLifecycleRule -Id 1 -ApplyToAllWorkspaces $true -ExpirationDays 1
```

Writes the key lifecycle rule as Files.com returns it.

### Example 2: Act on key lifecycle rules from the pipeline

```powershell
Get-FilesKeyLifecycleRule -Id 1 | Set-FilesKeyLifecycleRule -ApplyToAllWorkspaces $true -ExpirationDays 1
```

Takes the key lifecycle rule from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesKeyLifecycleRule -Id 1 -ApplyToAllWorkspaces $true -ExpirationDays 1 -WhatIf
```

Describes the change without sending anything to Files.com.
