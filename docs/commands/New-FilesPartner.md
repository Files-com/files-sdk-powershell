# New-FilesPartner

## SYNOPSIS

Create Partner.

## SYNTAX

### __AllParameterSets

```
New-FilesPartner [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Partner.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Create Partner

```powershell
New-FilesPartner -Name 'Acme Corp' -RootFolder '/AcmeCorp' -AiAssistantPersonalityId 1 -AllowedIps '10.0.0.0/8', '127.0.0.1'
```

Writes the partner returned.

### Example 2: Preview the change

```powershell
New-FilesPartner -Name 'Acme Corp' -RootFolder '/AcmeCorp' -AiAssistantPersonalityId 1 -AllowedIps '10.0.0.0/8', '127.0.0.1' -WhatIf
```

Describes the change without sending anything to Files.com.
