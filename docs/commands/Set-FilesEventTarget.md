# Set-FilesEventTarget

## SYNOPSIS

Update Event Target.

## SYNTAX

### Id (Default)

```
Set-FilesEventTarget [<parameters of the Id set>]
```

### InputObject

```
Set-FilesEventTarget [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Event Target.

The command accepts event targets from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Update Event Target

```powershell
Set-FilesEventTarget -Id 1 -Name 'example' -WorkspaceId 1
```

Writes the event target as Files.com returns it.

### Example 2: Act on event targets from the pipeline

```powershell
Get-FilesEventTarget -Id 1 | Set-FilesEventTarget -Name 'example' -WorkspaceId 1
```

Takes the event target from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesEventTarget -Id 1 -Name 'example' -WorkspaceId 1 -WhatIf
```

Describes the change without sending anything to Files.com.
