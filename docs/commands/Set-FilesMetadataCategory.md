# Set-FilesMetadataCategory

## SYNOPSIS

Update Metadata Category.

## SYNTAX

### Id (Default)

```
Set-FilesMetadataCategory [<parameters of the Id set>]
```

### InputObject

```
Set-FilesMetadataCategory [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Metadata Category.

The command accepts metadata categories from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Update Metadata Category

```powershell
Set-FilesMetadataCategory -Id 1 -Name 'Approval Workflow'
```

Writes the metadata category as Files.com returns it.

### Example 2: Act on metadata categories from the pipeline

```powershell
Get-FilesMetadataCategory -Id 1 | Set-FilesMetadataCategory -Name 'Approval Workflow'
```

Takes the metadata category from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesMetadataCategory -Id 1 -Name 'Approval Workflow' -WhatIf
```

Describes the change without sending anything to Files.com.
