# Set-FilesUserLifecycleRule

## SYNOPSIS

Update User Lifecycle Rule.

## SYNTAX

### Id (Default)

```
Set-FilesUserLifecycleRule [<parameters of the Id set>]
```

### InputObject

```
Set-FilesUserLifecycleRule [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update User Lifecycle Rule.

The command accepts user lifecycle rules from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Update User Lifecycle Rule

```powershell
Set-FilesUserLifecycleRule -Id 1 -Action 'disable' -ApplyToAllWorkspaces $true
```

Writes the user lifecycle rule as Files.com returns it.

### Example 2: Act on user lifecycle rules from the pipeline

```powershell
Get-FilesUserLifecycleRule -Id 1 | Set-FilesUserLifecycleRule -Action 'disable' -ApplyToAllWorkspaces $true
```

Takes the user lifecycle rule from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesUserLifecycleRule -Id 1 -Action 'disable' -ApplyToAllWorkspaces $true -WhatIf
```

Describes the change without sending anything to Files.com.
