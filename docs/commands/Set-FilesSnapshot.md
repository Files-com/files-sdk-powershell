# Set-FilesSnapshot

## SYNOPSIS

Update Snapshot.

## SYNTAX

### Id (Default)

```
Set-FilesSnapshot [<parameters of the Id set>]
```

### InputObject

```
Set-FilesSnapshot [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Snapshot.

The command accepts snapshots from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Update Snapshot

```powershell
Set-FilesSnapshot -Id 1 -ExpiresAt (Get-Date).AddDays(30) -Name 'My Snapshot'
```

Writes the snapshot as Files.com returns it.

### Example 2: Act on snapshots from the pipeline

```powershell
Get-FilesSnapshot -Id 1 | Set-FilesSnapshot -ExpiresAt (Get-Date).AddDays(30) -Name 'My Snapshot'
```

Takes the snapshot from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesSnapshot -Id 1 -ExpiresAt (Get-Date).AddDays(30) -Name 'My Snapshot' -WhatIf
```

Describes the change without sending anything to Files.com.
