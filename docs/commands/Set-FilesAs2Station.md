# Set-FilesAs2Station

## SYNOPSIS

Update AS2 Station.

## SYNTAX

### Id (Default)

```
Set-FilesAs2Station [<parameters of the Id set>]
```

### InputObject

```
Set-FilesAs2Station [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update AS2 Station.

The command accepts as2 stations from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Update AS2 Station

```powershell
Set-FilesAs2Station -Id 1 -Name 'AS2 Station Name' -PublicCertificate 'example'
```

Writes the as2 station as Files.com returns it.

### Example 2: Act on as2 stations from the pipeline

```powershell
Get-FilesAs2Station -Id 1 | Set-FilesAs2Station -Name 'AS2 Station Name' -PublicCertificate 'example'
```

Takes the as2 station from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesAs2Station -Id 1 -Name 'AS2 Station Name' -PublicCertificate 'example' -WhatIf
```

Describes the change without sending anything to Files.com.
