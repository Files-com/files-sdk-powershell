# New-FilesSnapshot

## SYNOPSIS

Create Snapshot.

## SYNTAX

### __AllParameterSets

```
New-FilesSnapshot [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Snapshot.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create Snapshot

```powershell
New-FilesSnapshot -ExpiresAt (Get-Date).AddDays(30) -Name 'My Snapshot'
```

Writes the snapshot returned.

### Example 2: Preview the change

```powershell
New-FilesSnapshot -ExpiresAt (Get-Date).AddDays(30) -Name 'My Snapshot' -WhatIf
```

Describes the change without sending anything to Files.com.
