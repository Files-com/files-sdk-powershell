# New-FilesAs2Station

## SYNOPSIS

Create AS2 Station.

## SYNTAX

### __AllParameterSets

```
New-FilesAs2Station [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create AS2 Station.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Create AS2 Station

```powershell
New-FilesAs2Station -Name 'AS2 Station Name' -WorkspaceId 1 -PublicCertificate 'example'
```

Writes the as2 station returned.

### Example 2: Preview the change

```powershell
New-FilesAs2Station -Name 'AS2 Station Name' -WorkspaceId 1 -PublicCertificate 'example' -WhatIf
```

Describes the change without sending anything to Files.com.
