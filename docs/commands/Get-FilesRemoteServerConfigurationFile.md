# Get-FilesRemoteServerConfigurationFile

## SYNOPSIS

Download configuration file (required for some Remote Server integrations, such as the Files.com Agent).

## SYNTAX

### __AllParameterSets

```
Get-FilesRemoteServerConfigurationFile [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Download configuration file (required for some Remote Server integrations, such as the Files.com Agent).

## EXAMPLES

### Example 1: Download configuration file (required for some Remote Server integrations, such as the Files.com Agent)

```powershell
Get-FilesRemoteServerConfigurationFile -Id 1
```

Writes the remote server configuration file returned.
