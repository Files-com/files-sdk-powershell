# New-FilesEventChannel

## SYNOPSIS

Create Event Channel.

## SYNTAX

### __AllParameterSets

```
New-FilesEventChannel [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Event Channel.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create Event Channel

```powershell
New-FilesEventChannel -Name 'example' -WorkspaceId 1 -Description 'example'
```

Writes the event channel returned.

### Example 2: Preview the change

```powershell
New-FilesEventChannel -Name 'example' -WorkspaceId 1 -Description 'example' -WhatIf
```

Describes the change without sending anything to Files.com.
