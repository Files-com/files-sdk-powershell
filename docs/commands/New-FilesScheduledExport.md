# New-FilesScheduledExport

## SYNOPSIS

Create Scheduled Export.

## SYNTAX

### __AllParameterSets

```
New-FilesScheduledExport [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Scheduled Export.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create Scheduled Export

```powershell
New-FilesScheduledExport -Name 'Monthly access review' -ExportType 'permission_audit' -ExportOptions @{ group_by = 'user' } -UserId 1
```

Writes the scheduled export returned.

### Example 2: Preview the change

```powershell
New-FilesScheduledExport -Name 'Monthly access review' -ExportType 'permission_audit' -ExportOptions @{ group_by = 'user' } -UserId 1 -WhatIf
```

Describes the change without sending anything to Files.com.
