# Set-FilesSftpHostKey

## SYNOPSIS

Update SFTP Host Key.

## SYNTAX

### Id (Default)

```
Set-FilesSftpHostKey [<parameters of the Id set>]
```

### InputObject

```
Set-FilesSftpHostKey [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update SFTP Host Key.

The command accepts sftp host keys from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Update SFTP Host Key

```powershell
Set-FilesSftpHostKey -Id 1 -Active $true -CustomDomainId 1
```

Writes the sftp host key as Files.com returns it.

### Example 2: Act on sftp host keys from the pipeline

```powershell
Get-FilesSftpHostKey -Id 1 | Set-FilesSftpHostKey -Active $true -CustomDomainId 1
```

Takes the sftp host key from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesSftpHostKey -Id 1 -Active $true -CustomDomainId 1 -WhatIf
```

Describes the change without sending anything to Files.com.
