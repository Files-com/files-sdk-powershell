# Update-FilesRemoteServerAgent

## SYNOPSIS

Push update to Files Agent.

## SYNTAX

### Id (Default)

```
Update-FilesRemoteServerAgent [<parameters of the Id set>]
```

### InputObject

```
Update-FilesRemoteServerAgent [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Push update to Files Agent.

The command accepts remote servers from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Push update to Files Agent

```powershell
Update-FilesRemoteServerAgent -Id 1
```

Writes the agent push update returned.

### Example 2: Act on remote servers from the pipeline

```powershell
Get-FilesRemoteServer -Id 1 | Update-FilesRemoteServerAgent
```

Takes the remote server from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Update-FilesRemoteServerAgent -Id 1 -WhatIf
```

Describes the change without sending anything to Files.com.
