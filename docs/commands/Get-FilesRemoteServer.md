# Get-FilesRemoteServer

## SYNOPSIS

List Remote Servers, or get one remote server by Id.

## SYNTAX

### List (Default)

```
Get-FilesRemoteServer [<parameters of the List set>]
```

### Page

```
Get-FilesRemoteServer [<parameters of the Page set>]
```

### Continuation

```
Get-FilesRemoteServer [<parameters of the Continuation set>]
```

### Id

```
Get-FilesRemoteServer [<parameters of the Id set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

List Remote Servers.

Show Remote Server.

Without -Page or -Continuation, the command writes each remote server of every page, loading one page at a time as the pipeline consumes them. -First and -Skip bound what it writes, and stopping the pipeline early, as Select-Object -First does, loads no further page. A failure on any page stops the command, so a partial listing is never taken for a complete one.

## EXAMPLES

### Example 1: List all remote servers

```powershell
Get-FilesRemoteServer
```

Writes every remote server, loading one page at a time as the pipeline consumes them.

### Example 2: Get one page at a time

```powershell
$page = Get-FilesRemoteServer -Page
$next = Get-FilesRemoteServer -Continuation $page.Continuation
```

Writes the first page as a FilesPage object, then the next page from its continuation.

### Example 3: Get one remote server

```powershell
Get-FilesRemoteServer -Id 1
```

Writes the remote server with that Id.
