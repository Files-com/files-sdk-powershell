# Get-FilesHistory

## SYNOPSIS

List site full action history.

## SYNTAX

### List (Default)

```
Get-FilesHistory [<parameters of the List set>]
```

### Page

```
Get-FilesHistory [<parameters of the Page set>]
```

### Continuation

```
Get-FilesHistory [<parameters of the Continuation set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

List site full action history.

Without -Page or -Continuation, the command writes each history of every page, loading one page at a time as the pipeline consumes them. -First and -Skip bound what it writes, and stopping the pipeline early, as Select-Object -First does, loads no further page. A failure on any page stops the command, so a partial listing is never taken for a complete one.

## EXAMPLES

### Example 1: List all histories

```powershell
Get-FilesHistory
```

Writes every history, loading one page at a time as the pipeline consumes them.

### Example 2: Get one page at a time

```powershell
$page = Get-FilesHistory -Page
$next = Get-FilesHistory -Continuation $page.Continuation
```

Writes the first page as a FilesPage object, then the next page from its continuation.
