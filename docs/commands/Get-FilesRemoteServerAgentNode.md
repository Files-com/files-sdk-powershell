# Get-FilesRemoteServerAgentNode

## SYNOPSIS

List Files.com Agent nodes.

## SYNTAX

### Id (Default)

```
Get-FilesRemoteServerAgentNode [<parameters of the Id set>]
```

### InputObject

```
Get-FilesRemoteServerAgentNode [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

List Files.com Agent nodes.

The command accepts remote servers from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

## EXAMPLES

### Example 1: List Files.com Agent nodes

```powershell
Get-FilesRemoteServerAgentNode -Id 1
```

Writes the agent node returned.

### Example 2: Act on remote servers from the pipeline

```powershell
Get-FilesRemoteServer -Id 1 | Get-FilesRemoteServerAgentNode
```

Takes the remote server from the pipeline and uses its Id and connection.
