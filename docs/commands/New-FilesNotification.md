# New-FilesNotification

## SYNOPSIS

Create Notification.

## SYNTAX

### __AllParameterSets

```
New-FilesNotification [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Notification.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create Notification

```powershell
New-FilesNotification -NotifyOnDelete $true -NotifyOnDownload $true
```

Writes the notification returned.

### Example 2: Preview the change

```powershell
New-FilesNotification -NotifyOnDelete $true -NotifyOnDownload $true -WhatIf
```

Describes the change without sending anything to Files.com.
