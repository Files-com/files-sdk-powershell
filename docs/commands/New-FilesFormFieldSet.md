# New-FilesFormFieldSet

## SYNOPSIS

Create Form Field Set.

## SYNTAX

### __AllParameterSets

```
New-FilesFormFieldSet [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Form Field Set.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create Form Field Set

```powershell
New-FilesFormFieldSet
```

Writes the form field set returned.

### Example 2: Preview the change

```powershell
New-FilesFormFieldSet -WhatIf
```

Describes the change without sending anything to Files.com.
