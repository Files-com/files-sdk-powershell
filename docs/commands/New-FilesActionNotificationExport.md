# New-FilesActionNotificationExport

## SYNOPSIS

Create Action Notification Export.

## SYNTAX

### __AllParameterSets

```
New-FilesActionNotificationExport [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Action Notification Export.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create Action Notification Export

```powershell
New-FilesActionNotificationExport -WorkspaceId 1 -StartAt (Get-Date).AddDays(30)
```

Writes the action notification export returned.

### Example 2: Preview the change

```powershell
New-FilesActionNotificationExport -WorkspaceId 1 -StartAt (Get-Date).AddDays(30) -WhatIf
```

Describes the change without sending anything to Files.com.
