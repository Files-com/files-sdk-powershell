# New-FilesGroup

## SYNOPSIS

Create Group.

## SYNTAX

### __AllParameterSets

```
New-FilesGroup [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Group.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Create Group

```powershell
New-FilesGroup -Name 'name' -AiAssistantPersonalityId 1 -FtpPermission $true
```

Writes the group returned.

### Example 2: Preview the change

```powershell
New-FilesGroup -Name 'name' -AiAssistantPersonalityId 1 -FtpPermission $true -WhatIf
```

Describes the change without sending anything to Files.com.
