# Start-FilesUploadSession

## SYNOPSIS

Begin File Upload.

## SYNTAX

### Path (Default)

```
Start-FilesUploadSession [<parameters of the Path set>]
```

### InputObject

```
Start-FilesUploadSession [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Begin File Upload.

The command accepts files from the pipeline as -InputObject, and uses each one's Path and the connection that fetched it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Begin File Upload

```powershell
Start-FilesUploadSession -Path 'path'
```

Writes each file upload part returned.

### Example 2: Act on files from the pipeline

```powershell
Get-FilesFile -Path 'path' | Start-FilesUploadSession
```

Takes the file from the pipeline and uses its Path and connection.

### Example 3: Preview the change

```powershell
Start-FilesUploadSession -Path 'path' -WhatIf
```

Describes the change without sending anything to Files.com.
