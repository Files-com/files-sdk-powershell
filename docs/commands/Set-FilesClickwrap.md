# Set-FilesClickwrap

## SYNOPSIS

Update Clickwrap.

## SYNTAX

### Id (Default)

```
Set-FilesClickwrap [<parameters of the Id set>]
```

### InputObject

```
Set-FilesClickwrap [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Clickwrap.

The command accepts clickwraps from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Update Clickwrap

```powershell
Set-FilesClickwrap -Id 1 -Name 'Example Site NDA for Files.com Use' -Body '[Legal body text]'
```

Writes the clickwrap as Files.com returns it.

### Example 2: Act on clickwraps from the pipeline

```powershell
Get-FilesClickwrap -Id 1 | Set-FilesClickwrap -Name 'Example Site NDA for Files.com Use' -Body '[Legal body text]'
```

Takes the clickwrap from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesClickwrap -Id 1 -Name 'Example Site NDA for Files.com Use' -Body '[Legal body text]' -WhatIf
```

Describes the change without sending anything to Files.com.
