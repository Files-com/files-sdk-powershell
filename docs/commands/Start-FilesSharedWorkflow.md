# Start-FilesSharedWorkflow

## SYNOPSIS

Run a Shared Workflow.

## SYNTAX

### Id (Default)

```
Start-FilesSharedWorkflow [<parameters of the Id set>]
```

### InputObject

```
Start-FilesSharedWorkflow [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Run a Shared Workflow.

The command accepts shared workflows from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Run a Shared Workflow

```powershell
Start-FilesSharedWorkflow -Id 1 -SubmissionRevision 'submission_revision' -SubmissionId 'submission_id' -FilePath 'file_path'
```

Writes the automation run returned.

### Example 2: Act on shared workflows from the pipeline

```powershell
Get-FilesSharedWorkflow -Id 1 | Start-FilesSharedWorkflow -SubmissionRevision 'submission_revision' -SubmissionId 'submission_id' -FilePath 'file_path'
```

Takes the shared workflow from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Start-FilesSharedWorkflow -Id 1 -SubmissionRevision 'submission_revision' -SubmissionId 'submission_id' -FilePath 'file_path' -WhatIf
```

Describes the change without sending anything to Files.com.
