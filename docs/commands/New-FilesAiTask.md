# New-FilesAiTask

## SYNOPSIS

Create Ai Task.

## SYNTAX

### __AllParameterSets

```
New-FilesAiTask [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Ai Task.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Create Ai Task

```powershell
New-FilesAiTask -Name 'Summarize daily reports' -Prompt 'Summarize the uploaded file and identify follow-up actions.' -Description 'Summarizes files uploaded by the accounting team.' -Disabled $true
```

Writes the ai task returned.

### Example 2: Preview the change

```powershell
New-FilesAiTask -Name 'Summarize daily reports' -Prompt 'Summarize the uploaded file and identify follow-up actions.' -Description 'Summarizes files uploaded by the accounting team.' -Disabled $true -WhatIf
```

Describes the change without sending anything to Files.com.
