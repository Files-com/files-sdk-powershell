# Set-FilesRemoteMountBackend

## SYNOPSIS

Update Remote Mount Backend.

## SYNTAX

### Id (Default)

```
Set-FilesRemoteMountBackend [<parameters of the Id set>]
```

### InputObject

```
Set-FilesRemoteMountBackend [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Remote Mount Backend.

The command accepts remote mount backends from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Update Remote Mount Backend

```powershell
Set-FilesRemoteMountBackend -Id 1 -Enabled $true -Fall 1
```

Writes the remote mount backend as Files.com returns it.

### Example 2: Act on remote mount backends from the pipeline

```powershell
Get-FilesRemoteMountBackend -Id 1 | Set-FilesRemoteMountBackend -Enabled $true -Fall 1
```

Takes the remote mount backend from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesRemoteMountBackend -Id 1 -Enabled $true -Fall 1 -WhatIf
```

Describes the change without sending anything to Files.com.
