# Set-FilesApiKey

## SYNOPSIS

Update API Key.

## SYNTAX

### Id (Default)

```
Set-FilesApiKey [<parameters of the Id set>]
```

### InputObject

```
Set-FilesApiKey [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update API Key.

The command accepts api keys from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Update API Key

```powershell
Set-FilesApiKey -Id 1 -Description 'example' -ExpiresAt (Get-Date).AddDays(30)
```

Writes the api key as Files.com returns it.

### Example 2: Act on api keys from the pipeline

```powershell
Get-FilesApiKey -Id 1 | Set-FilesApiKey -Description 'example' -ExpiresAt (Get-Date).AddDays(30)
```

Takes the api key from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesApiKey -Id 1 -Description 'example' -ExpiresAt (Get-Date).AddDays(30) -WhatIf
```

Describes the change without sending anything to Files.com.
