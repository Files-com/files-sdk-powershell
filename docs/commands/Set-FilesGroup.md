# Set-FilesGroup

## SYNOPSIS

Update Group.

## SYNTAX

### Id (Default)

```
Set-FilesGroup [<parameters of the Id set>]
```

### InputObject

```
Set-FilesGroup [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Group.

The command accepts groups from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Update Group

```powershell
Set-FilesGroup -Id 1 -AiAssistantPersonalityId 1 -FtpPermission $true
```

Writes the group as Files.com returns it.

### Example 2: Act on groups from the pipeline

```powershell
Get-FilesGroup -Id 1 | Set-FilesGroup -AiAssistantPersonalityId 1 -FtpPermission $true
```

Takes the group from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesGroup -Id 1 -AiAssistantPersonalityId 1 -FtpPermission $true -WhatIf
```

Describes the change without sending anything to Files.com.
