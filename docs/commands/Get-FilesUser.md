# Get-FilesUser

## SYNOPSIS

List Users, or get one user by Id.

## SYNTAX

### List (Default)

```
Get-FilesUser [<parameters of the List set>]
```

### Page

```
Get-FilesUser [<parameters of the Page set>]
```

### Continuation

```
Get-FilesUser [<parameters of the Continuation set>]
```

### Id

```
Get-FilesUser [<parameters of the Id set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

List Users.

Show User.

Without -Page or -Continuation, the command writes each user of every page, loading one page at a time as the pipeline consumes them. -First and -Skip bound what it writes, and stopping the pipeline early, as Select-Object -First does, loads no further page. A failure on any page stops the command, so a partial listing is never taken for a complete one.

## EXAMPLES

### Example 1: List all users

```powershell
Get-FilesUser
```

Writes every user, loading one page at a time as the pipeline consumes them.

### Example 2: Get one page at a time

```powershell
$page = Get-FilesUser -Page
$next = Get-FilesUser -Continuation $page.Continuation
```

Writes the first page as a FilesPage object, then the next page from its continuation.

### Example 3: Get one user

```powershell
Get-FilesUser -Id 1
```

Writes the user with that Id.
