# Get-FilesSyncLog

## SYNOPSIS

List Sync Logs.

## SYNTAX

### List (Default)

```
Get-FilesSyncLog [<parameters of the List set>]
```

### Page

```
Get-FilesSyncLog [<parameters of the Page set>]
```

### Continuation

```
Get-FilesSyncLog [<parameters of the Continuation set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

List Sync Logs.

Without -Page or -Continuation, the command writes each sync log of every page, loading one page at a time as the pipeline consumes them. -First and -Skip bound what it writes, and stopping the pipeline early, as Select-Object -First does, loads no further page. A failure on any page stops the command, so a partial listing is never taken for a complete one.

## EXAMPLES

### Example 1: List all sync logs

```powershell
Get-FilesSyncLog
```

Writes every sync log, loading one page at a time as the pipeline consumes them.

### Example 2: Get one page at a time

```powershell
$page = Get-FilesSyncLog -Page
$next = Get-FilesSyncLog -Continuation $page.Continuation
```

Writes the first page as a FilesPage object, then the next page from its continuation.
