# Set-FilesChildSiteManagementPolicy

## SYNOPSIS

Update Child Site Management Policy.

## SYNTAX

### Id (Default)

```
Set-FilesChildSiteManagementPolicy [<parameters of the Id set>]
```

### InputObject

```
Set-FilesChildSiteManagementPolicy [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Child Site Management Policy.

The command accepts child site management policies from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Update Child Site Management Policy

```powershell
Set-FilesChildSiteManagementPolicy -Id 1 -Value @{ color2_left = '#000000'; folder_behaviors = @(@{ behavior = 'file_expiration'; value = @{ days_to_retain = 30 } }) } -SkipChildSiteIds 1, 2
```

Writes the child site management policy as Files.com returns it.

### Example 2: Act on child site management policies from the pipeline

```powershell
Get-FilesChildSiteManagementPolicy -Id 1 | Set-FilesChildSiteManagementPolicy -Value @{ color2_left = '#000000'; folder_behaviors = @(@{ behavior = 'file_expiration'; value = @{ days_to_retain = 30 } }) } -SkipChildSiteIds 1, 2
```

Takes the child site management policy from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesChildSiteManagementPolicy -Id 1 -Value @{ color2_left = '#000000'; folder_behaviors = @(@{ behavior = 'file_expiration'; value = @{ days_to_retain = 30 } }) } -SkipChildSiteIds 1, 2 -WhatIf
```

Describes the change without sending anything to Files.com.
