# Set-FilesPartner

## SYNOPSIS

Update Partner.

## SYNTAX

### Id (Default)

```
Set-FilesPartner [<parameters of the Id set>]
```

### InputObject

```
Set-FilesPartner [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Partner.

The command accepts partners from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Update Partner

```powershell
Set-FilesPartner -Id 1 -AiAssistantPersonalityId 1 -AllowedIps '10.0.0.0/8', '127.0.0.1'
```

Writes the partner as Files.com returns it.

### Example 2: Act on partners from the pipeline

```powershell
Get-FilesPartner -Id 1 | Set-FilesPartner -AiAssistantPersonalityId 1 -AllowedIps '10.0.0.0/8', '127.0.0.1'
```

Takes the partner from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesPartner -Id 1 -AiAssistantPersonalityId 1 -AllowedIps '10.0.0.0/8', '127.0.0.1' -WhatIf
```

Describes the change without sending anything to Files.com.
