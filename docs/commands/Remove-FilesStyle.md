# Remove-FilesStyle

## SYNOPSIS

Delete Style.

## SYNTAX

### Path (Default)

```
Remove-FilesStyle [<parameters of the Path set>]
```

### InputObject

```
Remove-FilesStyle [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Delete Style.

The command accepts styles from the pipeline as -InputObject, and uses each one's Path and the connection that fetched it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Delete Style

```powershell
Remove-FilesStyle -Path 'path'
```

Sends the request and writes nothing when it succeeds.

### Example 2: Act on styles from the pipeline

```powershell
Get-FilesStyle -Path 'path' | Remove-FilesStyle
```

Takes the style from the pipeline and uses its Path and connection.

### Example 3: Preview the change

```powershell
Remove-FilesStyle -Path 'path' -WhatIf
```

Describes the change without sending anything to Files.com.
