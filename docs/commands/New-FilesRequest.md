# New-FilesRequest

## SYNOPSIS

Create Request.

## SYNTAX

### __AllParameterSets

```
New-FilesRequest [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Request.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create Request

```powershell
New-FilesRequest -Path 'path' -Destination 'destination'
```

Writes the request returned.

### Example 2: Preview the change

```powershell
New-FilesRequest -Path 'path' -Destination 'destination' -WhatIf
```

Describes the change without sending anything to Files.com.
