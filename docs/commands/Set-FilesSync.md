# Set-FilesSync

## SYNOPSIS

Update Sync.

## SYNTAX

### Id (Default)

```
Set-FilesSync [<parameters of the Id set>]
```

### InputObject

```
Set-FilesSync [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Sync.

The command accepts syncs from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Update Sync

```powershell
Set-FilesSync -Id 1 -DeleteEmptyFolders $true -Description 'example'
```

Writes the sync as Files.com returns it.

### Example 2: Act on syncs from the pipeline

```powershell
Get-FilesSync -Id 1 | Set-FilesSync -DeleteEmptyFolders $true -Description 'example'
```

Takes the sync from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesSync -Id 1 -DeleteEmptyFolders $true -Description 'example' -WhatIf
```

Describes the change without sending anything to Files.com.
