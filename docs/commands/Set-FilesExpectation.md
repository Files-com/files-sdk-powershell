# Set-FilesExpectation

## SYNOPSIS

Update Expectation.

## SYNTAX

### Id (Default)

```
Set-FilesExpectation [<parameters of the Id set>]
```

### InputObject

```
Set-FilesExpectation [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Expectation.

The command accepts expectations from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Update Expectation

```powershell
Set-FilesExpectation -Id 1 -Name 'Daily Vendor Feed' -Description 'Wait for the vendor CSV every morning.'
```

Writes the expectation as Files.com returns it.

### Example 2: Act on expectations from the pipeline

```powershell
Get-FilesExpectation -Id 1 | Set-FilesExpectation -Name 'Daily Vendor Feed' -Description 'Wait for the vendor CSV every morning.'
```

Takes the expectation from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesExpectation -Id 1 -Name 'Daily Vendor Feed' -Description 'Wait for the vendor CSV every morning.' -WhatIf
```

Describes the change without sending anything to Files.com.
