# New-FilesWebhookTest

## SYNOPSIS

Create Webhook Test.

## SYNTAX

### __AllParameterSets

```
New-FilesWebhookTest [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Webhook Test.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create Webhook Test

```powershell
New-FilesWebhookTest -Url 'https://www.site.com/...' -Method 'GET' -Encoding 'RAW'
```

Writes the webhook test returned.

### Example 2: Preview the change

```powershell
New-FilesWebhookTest -Url 'https://www.site.com/...' -Method 'GET' -Encoding 'RAW' -WhatIf
```

Describes the change without sending anything to Files.com.
