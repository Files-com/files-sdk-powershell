# Set-FilesSiemHttpDestination

## SYNOPSIS

Update SIEM HTTP Destination.

## SYNTAX

### Id (Default)

```
Set-FilesSiemHttpDestination [<parameters of the Id set>]
```

### InputObject

```
Set-FilesSiemHttpDestination [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update SIEM HTTP Destination.

The command accepts siem http destinations from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it. It asks for confirmation by default; use -Confirm:$false in scripts that have already decided.

## EXAMPLES

### Example 1: Update SIEM HTTP Destination

```powershell
Set-FilesSiemHttpDestination -Id 1 -Name 'example' -AdditionalHeaders @{ Authorization = 'Bearer YOUR_TOKEN' }
```

Writes the siem http destination as Files.com returns it.

### Example 2: Act on siem http destinations from the pipeline

```powershell
Get-FilesSiemHttpDestination -Id 1 | Set-FilesSiemHttpDestination -Name 'example' -AdditionalHeaders @{ Authorization = 'Bearer YOUR_TOKEN' }
```

Takes the siem http destination from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesSiemHttpDestination -Id 1 -Name 'example' -AdditionalHeaders @{ Authorization = 'Bearer YOUR_TOKEN' } -WhatIf
```

Describes the change without sending anything to Files.com.
