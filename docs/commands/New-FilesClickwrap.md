# New-FilesClickwrap

## SYNOPSIS

Create Clickwrap.

## SYNTAX

### __AllParameterSets

```
New-FilesClickwrap [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Clickwrap.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create Clickwrap

```powershell
New-FilesClickwrap -Name 'Example Site NDA for Files.com Use' -Body '[Legal body text]'
```

Writes the clickwrap returned.

### Example 2: Preview the change

```powershell
New-FilesClickwrap -Name 'Example Site NDA for Files.com Use' -Body '[Legal body text]' -WhatIf
```

Describes the change without sending anything to Files.com.
