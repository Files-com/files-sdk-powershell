# Set-FilesAutomation

## SYNOPSIS

Update Automation.

## SYNTAX

### Id (Default)

```
Set-FilesAutomation [<parameters of the Id set>]
```

### InputObject

```
Set-FilesAutomation [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update Automation.

The command accepts automations from the pipeline as -InputObject, and uses each one's Id and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Update Automation

```powershell
Set-FilesAutomation -Id 1 -Source 'example' -Destinations 'folder_a/file_a.txt', 'folder_b/'
```

Writes the automation as Files.com returns it.

### Example 2: Act on automations from the pipeline

```powershell
Get-FilesAutomation -Id 1 | Set-FilesAutomation -Source 'example' -Destinations 'folder_a/file_a.txt', 'folder_b/'
```

Takes the automation from the pipeline and uses its Id and connection.

### Example 3: Preview the change

```powershell
Set-FilesAutomation -Id 1 -Source 'example' -Destinations 'folder_a/file_a.txt', 'folder_b/' -WhatIf
```

Describes the change without sending anything to Files.com.
