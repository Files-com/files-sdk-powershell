# New-FilesBundleRecipient

## SYNOPSIS

Create Share Link Recipient.

## SYNTAX

### __AllParameterSets

```
New-FilesBundleRecipient [<parameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Create Share Link Recipient.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Create Share Link Recipient

```powershell
New-FilesBundleRecipient -BundleId 1 -Recipient 'johndoe@gmail.com' -Name 'John Smith' -Company 'Acme Ltd'
```

Writes the bundle recipient returned.

### Example 2: Preview the change

```powershell
New-FilesBundleRecipient -BundleId 1 -Recipient 'johndoe@gmail.com' -Name 'John Smith' -Company 'Acme Ltd' -WhatIf
```

Describes the change without sending anything to Files.com.
