# Set-FilesFile

## SYNOPSIS

Update File/Folder Metadata.

## SYNTAX

### Path (Default)

```
Set-FilesFile [<parameters of the Path set>]
```

### InputObject

```
Set-FilesFile [<parameters of the InputObject set>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Update File/Folder Metadata.

The command accepts files from the pipeline as -InputObject, and uses each one's Path and the connection that fetched it.

When given -InputObject, the command updates that object with the values Files.com returns and writes it.

The command supports -WhatIf, which describes the change without sending it to Files.com, and -Confirm, which asks before sending it.

## EXAMPLES

### Example 1: Update File/Folder Metadata

```powershell
Set-FilesFile -Path 'path' -CustomMetadata @{ department = 'finance' } -PriorityColor 'red'
```

Writes the file as Files.com returns it.

### Example 2: Act on files from the pipeline

```powershell
Get-FilesFile -Path 'path' | Set-FilesFile -CustomMetadata @{ department = 'finance' } -PriorityColor 'red'
```

Takes the file from the pipeline and uses its Path and connection.

### Example 3: Preview the change

```powershell
Set-FilesFile -Path 'path' -CustomMetadata @{ department = 'finance' } -PriorityColor 'red' -WhatIf
```

Describes the change without sending anything to Files.com.
